# CERTIFY SIEM–SOAR Component

This repository provides the SIEM–SOAR module developed within the CERTIFY project.
The component collects security events, applies correlation rules, and triggers automated actions to support monitoring and incident handling in the CERTIFY framework.

## Overview

The SIEM–SOAR module processes events coming from CERTIFY nodes and other system components.
It supports event ingestion, rule evaluation, alert generation, and automated responses.
The component is designed for integration with the CERTIFY security services and can be used to test or extend the behaviour of the monitoring chain.

If you want to use this component, or need the full version of the platform, please contact the Trust Up team (info [at] trustup.it).

## Requirements

To run this module, the following tools may be needed:

- Docker
- Docker Compose
- Python 3.10
- Linux x86_64 or equivalent environment

Exact requirements depend on the chosen deployment mode.
